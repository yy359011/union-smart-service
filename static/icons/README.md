# 图标说明

本目录存放底部导航栏图标，建议使用 48x48px 的 PNG 图片。

## 需要的图标文件

### TabBar 图标
- `home.png` / `home-active.png` - 首页
- `service.png` / `service-active.png` - 服务
- `message.png` / `message-active.png` - 消息
- `mine.png` / `mine-active.png` - 我的

## 图标规范

1. 尺寸：48x48px
2. 格式：PNG
3. 颜色：
   - 未选中：#999999 (灰色)
   - 选中：#1890FF (蓝色)
4. 风格：线性图标，简洁清晰

## 推荐图标来源

1. uView Plus 内置图标：可直接使用 u-icon 组件
2. Iconfont: https://www.iconfont.cn/
3. 阿里巴巴矢量图标库

## 替代方案

本项目已配置 uView Plus 的 u-icon 组件，可直接使用内置图标，无需额外图片资源。
